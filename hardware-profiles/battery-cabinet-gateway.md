# 硬件板级画像：智能换电柜多路 485 物联网网关

* **项目代号**：`换电柜 / 多路485网关`
* **主控芯片**：`CH32V307`（V3.7.1 已重构为**裸机前后台架构 + TIM2 1ms 时基 + DMA 双缓冲 + IDLE 空闲中断**）
* **辅控芯片**：独立 GPIO 检测从机 MCU（`ZIJI/EXAM/EXTI0`）
* **无线模组**：合宙 `Air780E` (EC618 4G Cat.1，运行 LuatOS，负责 MQTT 与远程差分 OTA)
* **EDA 工具**：嘉立创 EDA 专业版（`.eprj2`）

---

## 1. 供电架构
* **主电源输入**：AC 220V 市电 -> 开关电源转 DC 24V
* **板载低压供电**：`DC 24V`（16 路低侧输出）、`DC 12V`、`DC 5V/3.8V`（Air780E 峰值 2A）、`DC 3.3V`（MCU）

---

## 2. 串口与外设真实映射（核对自 `Dri_uart.c` 与 `main.c`）
* **USART1** (`PA9/PA10`, RE: `PA8`)：预留 485
* **USART2** (`PA2/PA3`, TTL)：安卓屏 / 4G 模组交互（`115200 8N1`，JSON + `"end"`，注意帧间隔 >= 35ms）
* **USART3** (`PB10/PB11`, TTL)：调试日志串口 / 涉水开关量从机 (`USE_DI`, `115200 8N1`)
* **UART4** (`PC10/PC11`, RE: `PA15`)：多路温度传感器（`9600 8N1`，Modbus 地址 `0x01`）
* **UART5** (`PC12/PD2`, RE: `PB3`)：485 涉水传感器备选（非 `USE_DI` 模式）
* **UART6** (`PC0/PC1`, RE: `PA0`)：预留 485
* **UART7** (`PC2/PC3`, RE: `PB1`)：智能空开 (`9600 8E1` 偶校验)；电表桩模块亦标记预留于 UART7
* **UART8** (`PC4/PC5`, RE: `PB0`)：烟雾传感器（`9600 8N1`，地址 = `dev_id`）

---

## 3. 16 路 24V 低侧输出 + 水泵 (`Inf_dev_relay`)
* **LOAD1 ~ LOAD16 (低电平触发)**：`PB8, PB9, PA4~PA7, PB12~PB15, PC6~PC9, PA11, PA12`
* **PUMP 17 (高电平触发)**：`PB5`

---

## 4. 注意事项
* `main.c` 中 `cJSON` 绑定了标准库 `malloc/free`（例外允许，需防范长期运行堆碎片；其余驱动模块仍严禁使用动态内存）。
* 板载 AT24C32 EEPROM：`0x0000` 起存传感器/设备配置（每设备 8 字节），`0x043C` 存上报间隔，`0x0440` 起存涉水设备配置。
