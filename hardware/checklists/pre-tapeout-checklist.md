# 原理图评审与 PCB 投板前自检清单 (Pre-Tapeout Checklist)

每次导出网表画 PCB 前、以及输出 Gerber / BOM / 坐标文件发嘉立创打板前，逐项勾选核查。

---

## 一、原理图阶段（导网表前必查）

- [ ] **启动与复位电路**：MCU `BOOT0` / 启动脚已对照官方 Datasheet 核实，加下拉电阻与切换跳线/按键，无悬空。
- [ ] **串口与控制线闭合**：所有跨页网络标号（如 `MCU_TXD/RXD`、485 `USARTx_DE`、4G `PWR_CTRL/RST_CTRL`）一一对应且方向交叉正确，无拼写不一致或单端悬空。
- [ ] **对外端子全连通**：接线端子（如 485 `CN1`、电源 `P1/DC1`、调试口 `H1/H2`）所有有效引脚均已接网，无遗留红色 `X`。
- [ ] **默认安全电平**：所有 RS-485 `DE/RE` 加 `10kΩ` 下拉；继电器/MOS 驱动具备上电默认关断状态；感性负载配续流二极管。
- [ ] **耐压与功耗裕量**：电源 TVS 选型留 20~25% 裕量；高压/24V 电阻核对封装功率（≥0805）；电解电容耐压留 1.5 倍以上裕量。
- [ ] **DNP / 不贴器件清晰标记**：预留电路（如不贴的 5V 降压、选焊 120Ω 终端电阻、RF π 型匹配空贴电容）已在属性与 BOM 中明确标 `NC/DNP`。
- [ ] **封装引脚与芯片手册核对**：核对非标封装（如 LQFP64 是否含 `PB2`、二/三极管 1-2-3 脚序、模组 `RSV` 脚是否误用）。

---

## 二、PCB 布局布线阶段（投板前必查）

- [ ] **强电安规与开槽**：AC 220V 初级距次级 `>= 6.0mm`，L-N `>= 2.5mm`，边框层机械防爬电槽宽 `1.5~2.0mm` 且位置准确无误切焊盘。
- [ ] **隔离岛完整性**：多路 RS-485 芯片下方 `>= 4.0mm` 全层禁铜禁走线，各通道隔离地相互完全断开，间距 `>= 2.0mm`。
- [ ] **4G 射频与大电流供电**：`ANT_MAIN` 顶层 50Ω 无过孔且两侧打屏蔽地孔；`+3.8V` 走线 `>= 2.0mm`，严格先过 `220uF` 再进模组 `VBAT`。
- [ ] **高速差分与参考地**：100M 网口 `MDI` 组内等长 `< 10mil`、参考完整 `GND`、RJ45 变压器下方全层挖空；USB 差分无残桩。
- [ ] **防护器件顺序**：SIM 卡按 `模组 → 22Ω → 33pF → ESD → 卡座`；485 按 `端子 → TVS → IC` 直线排列，无回头线。
- [ ] **DC-DC 与晶振**：输入电容距 `VIN/GND <= 2mm`，`SW` 短粗紧凑，`FB` 避开电感；晶振紧贴 MCU、下方表层挖空、底层完整地、四周包地孔。
- [ ] **孤岛铜与缝合地孔**：双面铺铜已消除死铜（孤岛铜）与锐角，板边与高频区按 `3~5mm` 打缝合地孔。

---

## 三、DFM 与制造输出阶段

- [ ] **DRC 0 错误**：运行设计规则检查确保 **0 DRC 错误、0 未连接飞线**。
- [ ] **结构与干涉检查**：3D 预览核对电解电容、共模电感、接线端子、RJ45、SMA 座、拨动开关、定位孔与外壳无机械干涉。
- [ ] **丝印清晰可读**：位号、极性标（`+`、二极管阴极杠、IC 1 脚圆点）、端子定义（`ACL/ACN`、`A1/B1~A4/B4`、`SWD`）清晰且不压焊盘、不被大器件遮挡。
- [ ] **生产文件三件套核对**：Gerber（含钻孔与槽孔层）、BOM（确认 DNP 项与立创编号）、SMT 坐标文件已核对版本与日期。
