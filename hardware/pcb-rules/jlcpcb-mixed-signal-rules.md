# 嘉立创工业混合信号 PCB 通用设计规则与手工布线规范

> 适用于含 **AC 220V 强电、DC-DC 开关电源、4G 射频、100M 以太网、隔离 RS-485** 的工业网关与控制器板卡（1oz 铜厚默认基准）。**全程严禁自动布线。**

---

## 1. 安全间距、线宽与阻抗规则表

| 网络 / 区域 | 载流或阻抗目标 | 线宽 / 线距 / 安全间距 | 核心约束 |
|---|---|---|---|
| **AC 220V (`ACL/ACN`)** | 市电强电主回路 | 线宽 `>= 1.5~2.0mm`；L-N 间距 `>= 2.5mm` | 距次级低压区 `>= 6.0mm`，边框层开 `1.5~2.0mm` 机械防爬电槽 |
| **整流高压母线 (`±310V`)** | AC-DC 初级直流高压 | 线宽 `>= 1.0mm`；极间间距 `>= 2.5mm` | 储能电解紧贴模块引脚，全层禁铺低压铜皮 |
| **4G 脉冲电源 (`+3.8V`)** | 射频突发峰值 `2A` | 线宽 `>= 2.0mm`（或铜皮敷设） | 换层并联 3~4 个电源过孔，禁串磁珠防 DCR 压降 |
| **主干电源 (`+24V / +12V`)** | 主板总输入干线 | 线宽 `>= 1.2~1.5mm`（大负载按 1mm/A 放大） | 防反接/或门二极管阴极粗线汇流至各 DC-DC 输入端 |
| **系统低压 (`+5V / 3V3`)** | MCU / 外设供电 | 主干 `>= 0.8~1.0mm`；支路 `>= 0.3mm` | 星型分支，先过电容焊盘再进芯片引脚 |
| **4G 射频馈线 (`ANT_MAIN`)** | `50Ω` 单端阻抗 | 按嘉立创叠层算共面波导（双层约 30~40mil，4层参考 L2 约 18~20mil） | 仅走顶层严禁打孔，两侧包地打屏蔽过孔（间距 `<= 1.5mm`） |
| **100M 以太网 (`MDI` 差分)** | `100Ω` 差分阻抗 | 参考 7mil 宽 / 8mil 距（按实际叠层复核） | 组内等长误差 `< 10mil`，对间间距 `>= 3W`，底层参考完整 `GND` |
| **USB 2.0 (`DP/DM` 差分)** | `90Ω` 差分阻抗 | 按实际叠层设置 90Ω 差分对 | ESD 采用穿线走法无残桩，经切换开关时紧贴布局极短直连 |
| **RS-485 隔离带与地岛** | `2.5kV ~ 5kVrms` | 初次级隔离带 `>= 4.0mm`；各通道岛间 `>= 2.0mm` | 隔离芯片下方全层禁铜禁走线，多路隔离地严禁互连 |
| **常规信号与过孔** | GPIO / UART / I2C / SPI | 线宽 `8~10mil`；间距 `>= 6mil`；铺铜间距 `8~10mil` | 信号过孔 `20/12mil`；电源过孔 `24~30/14~18mil` |

## 2. 推荐手工布线 7 步标准顺序

严格按先强电高压、后射频高速、再功率电源、最后低速信号次序布线：

1. **定板框、定位孔与强电隔离槽**：锁定外壳接口位置，划定 AC 220V 强电区并绘制 `1.5~2.0mm` 防爬电机械槽。
2. **布 4G 射频与 `+3.8V` 脉冲供电**：先走 `50Ω` 天线馈线并包地打孔；再铺 `DC-DC -> 220uF -> 10uF/100nF/33pF -> VBAT` 宽电源路径。
3. **布高速差分对（以太网 / USB）**：先拉 `MDI` 100Ω 差分等长线并挖空变压器下方所有层；再拉 USB 90Ω 差分线。
4. **布多路隔离 RS-485 隔离岛**：先拉通 `>= 4.0mm` 隔离带与相互独立的地岛，再按 `端子 -> TVS -> 隔离芯片` 直线布通，两侧去耦电容同层紧贴 IC。
5. **布通 DC-DC 功率降压回路**：完成输入电容（`<= 2mm`）、紧凑 `SW` 节点、自举电容、输出电容地回流与远离电感的 `FB` 反馈线。
6. **布 MCU 晶振、去耦与常规低速线**：紧靠引脚放置晶振并表层挖空/底层铺地/四周打孔包地；逐个就近连接去耦电容，最后走 SWD、UART、DE 与 LED 控制线。
7. **整板铺铜、缝合地孔与 DRC 清零**：双面铺设系统 `GND`、清除孤岛铜与尖角铜皮，按 `3~5mm` 间距打缝合地孔阵列，运行 DRC 确保 **0 错误**。
