## 2. 硬件与 PCB 核心铁律（严守红线）

### 2.1 坚决杜绝自动布线
- 凡涉及 **AC 220V 强电、开关电源（DC-DC）、4G/射频天线、以太网/USB 高速差分、隔离 RS-485/CAN** 的混合信号板卡，**严禁使用自动布线**，必须全程纯手工规划分区、回路面积与参考平面。

### 2.2 强电安规与多地平面物理隔离
- **AC 220V 强电区**：火线/零线（`ACL/ACN`）间距 `>= 2.5mm`；初级高压区（含整流后约 310V 直流母线电容）与次级低压区爬电距离 **`>= 6.0mm`**，并在初次级间边框层绘制 **`1.5mm ~ 2.0mm` 机械防爬电开槽**；压敏电阻必须置于保险丝之后。
- **多路隔离 RS-485/CAN**：隔离芯片（如 `CA-IS3092W`）正下方必须拉通 **`>= 4.0mm` 全层禁铜禁走线隔离带**；多通道隔离地（如 `GND_4851 ~ GND_4854`）严禁彼此互连，独立地岛间距 `>= 2.0mm`。
- **机壳屏蔽地（`CHS_GND` / `SH`）**：网口与金属外壳屏蔽地严禁随意直连数字 `GND`，也不宜完全悬空；推荐预留 **`1MΩ` 电阻并联 `1nF/2kV` 高压电容**单点桥接 `GND`，或直接接机壳大地。

### 2.3 电源选型、余量与功率环路铁律
- **保护器件耐压裕量**：电源口 TVS 的关断电压 $V_{RWM}$ 须留出 **20% ~ 25% 裕量**（例如 12V 电源优先选 `SMBJ15CA`，慎用临界 `SMBJ12CA`）。
- **4G 模组脉冲供电**：`ML307R` / `Air780E` 等 4G 模组 `VBAT` 必须独立提供 **`3.6V ~ 3.8V`（2A 以上能力）**，严禁偷懒与系统 `3.3V` 共用，严禁在 `VBAT` 主路串联磁珠（避免 DCR 压降导致发射瞬间掉电重启）；走线严格按 **`DC-DC → 220uF 大电容 → 10uF/100nF/33pF → VBAT 引脚`** 顺序。
- **DC-DC 开关电源（如 `SCT2330`）**：输入电容距 `VIN/GND <= 2mm`；`SW` 开关节点短粗紧凑、禁止大面积铺铜辐射；`FB` 分压电阻紧贴芯片、采样线从末级输出电容引出并远离电感。
- **去耦电容顺序**：所有 MCU 与 IC 电源去耦严格遵循**“主干电源 → 去耦电容焊盘 → 芯片引脚”**；内核 LDO 输出脚（如 `VDDK`）严禁向外电路供电。

### 2.4 射频、高速差分与防护器件摆放顺序
- **4G 射频馈线（50Ω）**：顶层直线或平滑钝角/弧线直连，**严禁打过孔换层**；按实际板厚与叠层计算共面波导线宽，匹配件紧贴馈线，两侧伴地并打屏蔽过孔（间距 `<= 1.5mm`）。
- **100M 以太网差分对（100Ω）**：组内等长误差 `< 10mil`，两对间保持 `>= 3W` 间距防串扰，下方保持完整连续 `GND` 平面；RJ45 集成网络变压器正下方全层挖空禁铜禁走线。
- **USB 高速差分（90Ω）**：ESD 保护管采用穿线走法不拉分支残桩；经过切换开关（如拨动开关）时须紧贴布局缩短路径。
- **接口防护顺序（绝不放死角）**：
  - **RS-485**：`接线端子 → TVS (SM712) 就近粗线接隔离地 → 隔离收发器 A/B`。
  - **SIM 卡**：`4G 模组 → 22Ω 串阻（最靠近模组）→ 33pF 滤波电容 → ESD 保护管（最靠近卡座）→ SIM 卡座`。

### 2.5 软硬协同防坑检查（画原理图阶段必须核查）
- 任何外设引出前必须对照 [`chips/`](../chips/) 确认芯片引脚限制（例如 `ML307R-DC` 移除了原生 Camera 接口、`Pin 26 RSV` 无 GPIO 映射、`Pin 8 VCC_CAMA` 不可外灌电源）。
- RS-485 `DE/RE` 控制线必须加 **`10kΩ` 下拉电阻**，防止 MCU 上电复位期间驱动总线引发冲突。
- MCU `BOOT0`（或启动模式脚）严禁悬空，必须核对官方 Datasheet 补齐下拉电阻与烧录切换方式。
- 低侧 N-MOS（如 `20N06`）驱动感性负载必须遵循 [`low-side-20n06-traps.md`](../chips/power-switches/low-side-20n06-traps.md)：栅极串 `47Ω ~ 100Ω` 阻尼电阻、上拉电阻放 MCU 侧且注意 24V 功耗封装（≥0805）。

## 3. 硬件知识库目录职责与资产边界
- `hardware/circuits/`：已验证可复用的标准单元电路设计要点。
- `hardware/pcb-rules/`：嘉立创工艺叠层阻抗、线宽载流、安全间距与手工布线标准。
- `hardware/bom-preferred/`：个人优选元器件型号、封装与选型避坑表。
- `hardware/checklists/`：原理图评审、投板前 PCB/DFM 自检与首板点亮清单。
- **大体积二进制资产隔离**：本仓库保持纯 Markdown 轻量结构，`.eprj2` 工程、3D STEP 外壳模型与大型原厂 PDF 手册请存放于外部目录或网盘，仓库内仅保留精炼摘要与经验卡片。
- **EDA 自动化工具链**：使用 `easyeda.exe` CLI / Daemon / MCP 辅助审计时，遵守根目录 [`easyeda-agent-env.md`](../easyeda-agent-env.md) 与 `99_AI_Scripts/` 脚本隔离规范。
